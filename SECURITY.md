# Security policy

## Supported versions

Only the latest release receives security fixes. Upgrade with
`brew upgrade outlook-busy-sync` or `scoop update outlook-busy-sync`.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's
**Security** tab and choose **Report a vulnerability**
(https://github.com/michalkechner-impact/outlook-busy-sync/security/advisories/new).
Please do not open a public issue.

Include the version (`outlook-busy-sync --version`), your OS and the steps
to reproduce. Leave out access tokens, tenant IDs and calendar content; they
are not needed to reproduce a bug.

There is no guaranteed response time. A fix and a published advisory come
before any details are made public.
